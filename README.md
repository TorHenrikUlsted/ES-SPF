# 🌿 Nyhavna
Eco‑Social Selection and Planning Framework (ES‑SPF)

The Eco‑Social Selection and Planning Framework (ES‑SPF) is a structured approach for restoring degraded or transformed areas using native species. It integrates four key dimensions:

1. Ecology — assessing site conditions, habitat potential, and species suitability

2. Society — considering local needs, cultural values, and community priorities

3. Policy — aligning restoration choices with regulations, strategies, and long‑term governance

4. Planning — guiding practical implementation, spatial design, and adaptive management

Together, these components support evidence‑based, socially grounded, and ecologically sound restoration of the Nyhavna area.
